# AI-Driven Multimodal Healthcare System

An integrated web application that leverages Deep Learning, Computer Vision, and Generative AI to provide preliminary diagnostics and healthcare management assistance.

## 🚀 Key Features
- **Brain Tumor MRI Classification:** Automated detection and classification of brain tumor MRI scans using Convolutional Neural Networks (CNN).
- **Multimodal Health Diagnostics:** Modular support for multiple medical diagnostic pipelines, including skin condition screening.
- **Interactive Web Interface:** User authentication, patient dashboard, test result tracking, and appointment booking powered by Flask and Jinja2 templates.
- **Conversational Health Assistant:** Integrated AI chatbot for interactive patient health inquiries.

## 🛠️ Tech Stack
- **Backend:** Python 3.11, Flask
- **Machine Learning & Vision:** TensorFlow, Keras, OpenCV, NumPy
- **Frontend:** HTML5, CSS3, JavaScript, Jinja2 Templates

## 💻 Local Setup & Execution

1. **Clone the repository:**
   \`bash
   git clone https://github.com/charangara03/AI-Driven-Multimodal-Healthcare-System.git
   cd AI-Driven-Multimodal-Healthcare-System
   \`

2. **Install dependencies:**
   \`bash
   pip install -r requirements.txt
   \`

3. **Configure Environment:**
   \`bash
   set OPENAI_API_KEY=your_api_key_here
   \`

4. **Run the application:**
   \`bash
   python main.py
   \`
   Access the dashboard locally at \`http://127.0.0.1:5000\`.
